Important Warning: No Automatic Bounds Checking

Session 3

Slide 34/43

What it means

  • If size is 5, valid indices are only 0 to 4.
  • C++ does not automatically protect basic arrays from invalid indexing.

Unsafe example

int a[5] = {1,2,3,4,5};
cout << a[5];   // invalid

This is out of bounds and unsafe.

Safe Indexing Rules

Session 3

Slide 36/43

Rule 1

For size n, valid indices are 0 to n - 1.

Rule 2

Use loop conditions like i < size.

Rule 3

Never assume an extra element exists.

Rule 4

When calling functions, pass the size too.

Debugging Practice

Session 3

Slide 39/43
Find the error

What is wrong in this loop?

int a[5];
for (int i = 0; i <= 5; i++)
    cout << a[i];
↻
Answer

The loop condition is wrong. For size 5, the correct condition is i < 5, not i <= 5.

Find the error

Why can this function be unsafe?

void show(int arr[]) {
    for (int i = 0; i < 10; i++)
        cout << arr[i];
}
↻
Answer

Because the loop assumes 10 elements even though the function does not know the real array size.
