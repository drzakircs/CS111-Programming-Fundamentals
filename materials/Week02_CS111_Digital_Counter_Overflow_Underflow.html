Teaching Explanation

A fixed-digit counter can only display values from 0 to 10n − 1, where n is the number of digits.

If you increase the counter beyond its maximum value, it wraps back to 0. That is a simple visual model of overflow.

If you decrease the counter below 0, it wraps to the highest value. That is a simple visual model of underflow.
For 4 digits: range = 0000 to 9999 Overflow example: 9999 + 1 → 0000 Underflow example: 0000 - 1 → 9999
