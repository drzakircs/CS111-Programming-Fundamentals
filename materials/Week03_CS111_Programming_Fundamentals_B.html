A condition is a question with a true or false answer.

Plain meaning

A condition asks whether something is true.

Examples:

Each expression evaluates to either true or false.

From Condition to if

The if statement uses a condition to control execution.

If the condition is false, the block is skipped.

}

Expanding the if Statement

An if block may contain several statements.
if (balance < 1000) {
    cout << "Low balance" << endl;
    cout << "Please deposit funds";
}

Execution rule

If the condition is true, all statements inside the braces run in order.

If false, all statements inside the braces are skipped.

This matches the course guide phrase “expanding the if statement”.

Nested if

A decision inside another decision.

When to use it?

Use nested if when a second condition should only be checked after the first condition is satisfied.

if (condition1) {
    if (condition2) {
        // both are true
    }
}
Introduce as “stage-by-stage checking”.

Order Matters

Wrong order gives wrong logic.

Wrong

if (marks >= 70)
    cout << "C";
else if (marks >= 80)
    cout << "B";
else if (marks >= 90)
    cout << "A";

For 92, output becomes C.

Correct

if (marks >= 90)
    cout << "A";
else if (marks >= 80)
    cout << "B";
else if (marks >= 70)
    cout << "C";

For 92, output becomes A.

A common logic error. Students must learn to order conditions carefully.

CS111 • Week 03 • Session 2

Dangling else

Which if does else belong to?
if (x > 0)
    if (y > 0)
        cout << "A";
    else
        cout << "B";

Rule

The else belongs to the nearest unmatched if.

Here, else belongs to if (y > 0).

Use indentation and braces to remove ambiguity.
CS111 • Week 03 • Session 2

Fix Dangling else

Use braces for clarity.

Clear version

if (x > 0) {
    if (y > 0) {
        cout << "A";
    }
    else {
        cout << "B";
    }
}

Lesson

  • Braces make code structure visible.
  • Readable code prevents logic confusion.
  • Beginners should use braces consistently.
Emphasize style and correctness.

CS111 • Week 03 • Session 3

Missing break Problem

Fall-through can cause unexpected output.

Without break

switch (choice) {
    case 1:
        cout << "One";
    case 2:
        cout << "Two";
}

If choice is 1, both One and Two may print.

With break

case 1:
    cout << "One";
    break;

Execution stops after the matched case.

Make fall-through visible as a common bug.
CS111 • Week 03 • Session 3

if/else-if vs switch

Choose the right tool.

Use if / else-if

  • Range checks
  • Different conditions
  • Logical operators
  • Complex comparisons

Use switch

  • One variable
  • Exact values
  • Menu options
  • Cleaner case handling
This is a design decision, not just syntax.
