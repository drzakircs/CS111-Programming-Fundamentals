Mathematics

Programming idea

CS111 Programming Fundamentals • Dr. Zakir Khan

Function: factorial()

An iterative factorial function.
Week 05 • Session 3
Slide 50/60
int factorial(int n) {
    int product = 1;

    for (int i = 1; i <= n; i++) {
        product = product * i;
    }

    return product;
}

Meaning

  • Start product at 1
  • Multiply by each number
  • Return final product
