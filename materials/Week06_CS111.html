What is Scope?

Slide 4/60
S

Simple Meaning

Scope tells us where a variable name can be used in a program.

L

Local Scope

Visible only inside the function or block where it is declared.

G

Global Scope

Visible to many functions because it is declared outside them.

Analogy: A classroom key. A local key works for only one room. A global key can open many rooms.

Recursive Factorial Function
