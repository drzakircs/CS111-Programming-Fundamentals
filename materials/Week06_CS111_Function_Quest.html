Instructor guide • 3 sessions

Session 16: Missions 1–4 (control switching, caller/callee frames, local/global/static scope, references and defaults). Make students draw the memory picture before clicking.

Session 17: Missions 5 and 8 (overloading, inline, std::exit), plus ask students to modify each C++ example in their IDE.

Session 18: Missions 6–7 (factorial and Fibonacci recursion), compare call count and stack depth with a loop, then run the challenges.

Assessment: One conceptual challenge per mission. +100 XP for a correct answer. Navigation remains unlocked for classroom demonstrations.

Accuracy note: This is a guided trace, not a full C++ compiler/interpreter. Stack frames, parameter copies and static lifetimes are illustrated without claiming fixed physical byte placement. The inline specifier is not a guarantee of machine-code inlining. Calling std::exit does not normally unwind automatic local variables.
