Conditions are the foundation of decision making.

C++ syntax

The simple if statement

if (condition) { statement1; statement2; }

Meaning

  • Evaluate the condition.
  • If true, execute the block.
  • If false, skip the block.
  • Then continue with the next statement.

Error-based learning

Without braces, only one statement belongs to if

Risky style

if (isAdmin) cout << "Access granted"; cout << "Log entry";

Only the first cout is controlled by the if.

Safer style

if (isAdmin) { cout << "Access granted"; cout << "Log entry"; }

Both statements are part of the block.

Cyber security context

Password length validation

Concept

This is a simple decision: one condition is tested, and one action is performed only when the condition is true.

Two-way decisions

Sometimes both outcomes need a defined action

if (marks >= 50) { cout << "Pass"; } else { cout << "Fail"; }

Meaning

If the condition is true, execute the if block. Otherwise, execute the else block.

Exactly one of the two branches executes.

Multi-branch logic

else-if checks conditions in order

if (marks >= 85) { grade = 'A'; } else if (marks >= 70) { grade = 'B'; } else if (marks >= 50) { grade = 'C'; } else { grade = 'F'; }

Important rule

Once a true condition is found, its block executes and the remaining conditions are skipped.

Order matters

Nested decisions

Some decisions happen only after another decision succeeds

if (usernameOK) { if (passwordOK) { cout << "Login allowed"; } else { cout << "Wrong password"; } } else { cout << "Unknown user"; }

Meaning

A nested if places one decision inside another. It is useful for multi-stage checks.

Common confusion

Dangling else attaches to the nearest unmatched if

Ambiguous-looking code

if (a) if (b) cout << "X"; else cout << "Y";

How C++ reads it

if (a) { if (b) { cout << "X"; } else { cout << "Y"; } }
Predict

Which if does the else belong to?

Ask Students
In nested if statements without braces, an else is matched with which if?
↻
Answer
It is matched with the nearest unmatched if. To avoid confusion, use braces and indentation clearly.
↻
Design choice

Nested if vs else-if ladder

Use nested if when...

  • Checks are dependent.
  • Later checks matter only if earlier checks pass.
  • Example: username → password → 2FA.

Use else-if when...

  • Choices are alternatives.
  • Only one category should be selected.
  • Example: grade A/B/C/F.
Error-based learning

Find the error in range classification

if (marks >= 50) { cout << "Pass"; } else if (marks >= 85) { cout << "Excellent"; }

Question

Why will “Excellent” never print?

Reason?
Think about condition order.
↻
Answer
Any mark ≥ 85 is also ≥ 50, so the first branch captures it. Check the stricter condition first.

Checking numeric ranges

Range checks need logical AND

if (marks >= 0 && marks <= 100) { cout << "Valid marks"; } else { cout << "Invalid marks"; }

Why AND?

Marks must satisfy both boundaries: not below 0 and not above 100.

Range condition = lower limit + upper limit.

Conditional operator

A compact form of simple if/else

string status; status = (attempts < 3) ? "Allowed" : "Locked";

Pattern

condition ? value_if_true : value_if_false

Use it for simple selections, not complex multi-line logic.

switch statement

switch is useful for fixed menu choices

switch (choice) { case 1: cout << "Scan"; break; case 2: cout << "Report"; break; default: cout << "Invalid"; }

Key points

  • Use cases for fixed values.
  • break stops fall-through.
  • default handles unmatched choices.

Common mistake

What happens if break is missing?

Ask Students
In a switch statement, why is break usually written after each case?
↻
Answer
Without break, execution can continue into the next case. This is called fall-through. Sometimes it is intentional, but beginners should avoid it unless clearly required.
