C++ rule: unsigned integer arithmetic wraps modulo 2N. Signed integer overflow is undefined behavior; a wrap-around shown here for signed types is only a two's-complement teaching model, not a C++ guarantee.

3. Teaching Interpretation

OverflowA computed value is greater than the maximum representable value of the selected data type.
Underflow (integer-range context)A computed value is less than the minimum representable value of the selected data type.
Signed TypeUses one bit pattern range for negative and positive values. Example: int8_t = −128 to 127.
Unsigned TypeStores only non-negative values. Example: uint8_t = 0 to 255.
Classroom prompt: “If a data type has only N bits, how many distinct bit patterns can it represent?” → 2N.

4. C++ Connection

#include <iostream> #include <cstdint> #include <limits> using namespace std; int main() { cout << numeric_limits<int8_t>::min() << "\n"; cout << numeric_limits<int8_t>::max() << "\n"; uint8_t x = 255; x = x + 1; // wraps to 0 for unsigned 8-bit arithmetic }
Important: fixed-width types such as int8_t and uint32_t make the bit width explicit. Plain C++ types such as int are implementation-dependent in size.
