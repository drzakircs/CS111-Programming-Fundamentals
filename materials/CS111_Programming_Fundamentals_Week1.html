Programs and programming languages

Program ≠ Programming Language

📋

Program

A specific set of instructions and data that performs a task.

Example: a program that reads two numbers and displays their sum.

🗣️

Programming Language

A formal language used to express instructions in a form that can be translated for the computer.

Examples: C++, C, Java, Python.

Analogy: the recipe is the program; English/Urdu is the language used to write it. The same idea may be expressed in different languages.

Concept check

Algorithm or not?

Ask Students
“Keep checking the log until it looks safe.”

Is this a valid algorithmic instruction?
↻
Suggested Answer
No. “Looks safe” is ambiguous. The stopping rule is also unclear. A program needs a measurable condition, for example: process exactly N records, or stop when a specific end marker is reached.

The parts of a C++ program

Every line has a purpose

using → simplify standard-library names
main() → program entry function
{ } → define a block

Header files

What does #include <iostream> mean?

#include
<iostream>

Concept

A header provides declarations for reusable library facilities.

For our first programs, <iostream> provides stream-based input/output facilities such as cout and cin.

#include is handled before normal compilation.

The using directive

Why do beginner examples often write using namespace std;?

Without the directive

std::cout << "Hello"; std::string name;

With the directive

using namespace std; cout << "Hello"; string name;

Concept: names such as cout belong to the standard namespace std. The directive lets beginner code omit the std:: prefix.

Program structure

main() is where execution begins

int main() { cout << "Start"; cout << "End"; return 0; }

Read it top → down

  • Enter main().
  • Execute the first output statement.
  • Execute the second output statement.
  • return 0; indicates normal completion.

Execution order matters. The computer follows the sequence you specify.

Single-line and multi-line comments

Comments explain code to humans

Single-line

// Display a welcome message cout << "Welcome";

Everything after // on that line is a comment.

Multi-line

/* Program: Login Demo Purpose: Show output */

Text between /* and */ is a block comment.

Good comments explain purpose or reasoning. They should not restate obvious syntax.

The #define directive

A preprocessor definition is handled before compilation

#define MAX_ATTEMPTS 3 cout << MAX_ATTEMPTS;

Beginner mental model

The preprocessor associates the name MAX_ATTEMPTS with the replacement text 3 before the compiler processes the program.

Later in this session/week we will compare this with a typed named constant using const.

Interactive activity · Identifiers

Valid C++ identifier or not?

Select each name to classify it.

Rules: begin with a letter or underscore; then letters/digits/underscore; no spaces/hyphens; keywords are reserved.
Data types

The type tells C++ what kind of value a variable stores

int

Whole numbers

0, 3, -15, 2048

float / double

Real numbers

3.14, 0.75, -2.5

bool

Logical state

true or false

string

Text

"student01"

Why types matter: they affect valid operations, storage representation and how the value is interpreted.

int · float · double

Choose a type that matches the kind of data

int

Whole-number values.

int failed = 4;
counts · indexes · quantities

float

Single-precision floating-point values.

float score = 7.5f;
fractional measurements

double

Double-precision floating-point values.

double rate = 0.125;
more precision than float
Avoid promising exact byte sizes here. C++ guarantees minimum ranges; exact sizes are implementation-dependent. Use sizeof on the next slide to observe the current system.

Determining the size of a data type

sizeof reports storage size in bytes

cout << sizeof(int); cout << sizeof(double); cout << sizeof(bool);

Important interpretation

The exact result can depend on the implementation/platform.

sizeof(type) is therefore the correct way to inspect the storage size on the system being used.

Do not memorize one universal byte count for every platform.

Variable assignments and initialization

Three related actions — not the same thing

Declaration

int attempts;

Create a variable with a type and name.

Initialization

Give the variable its first value as it is created.

Assignment

attempts = 4;

Replace the current value later.

Interactive state update

Assignment changes the stored value

attempts3
After initialization, attempts stores 3.

= in C++ means assignment: evaluate the right side, then store the result in the left-side variable.

Scope

Scope answers: “Where can this name be used?”

int main() { int outer = 10; { int inner = 20; cout << outer; // visible cout << inner; // visible } cout << outer; // visible // inner is not visible here }

Beginner rule

A variable declared inside a block { } is available only within its permitted scope.

Smaller, clear scopes reduce accidental misuse of data.

Arithmetic operators

C++ notation for basic arithmetic

+Addition8 + 2 → 10
-Subtraction8 - 2 → 6
*Multiplication8 * 2 → 16
/Division8 / 2 → 4
%Remainder8 % 3 → 2

Expression: a combination of values, variables and operators that produces a result.

Beginner misconception

Predict the result

Predict
int result = 7 / 2;

What value is stored in result?
↻
Answer
3. Both operands are integers, so integer division discards the fractional part. A floating-point operand is needed to obtain 3.5.
↻
Mathematical expressions

Translate the mathematics into explicit C++ operations

Mathematical idea

total = price × quantity + tax

C++ expression

total = price * quantity + tax;

C++ uses * for multiplication and requires explicit operators.

Programming is not handwriting: 2x is not multiplication syntax in C++; write 2 * x.

Operator precedence

Which operation happens first?

1( )Parentheses group what should be evaluated first.
2*   /   %Multiplication, division and remainder.
3+   -Addition and subtraction.
int x = 2 + 3 * 4; // x becomes 14 int y = (2 + 3) * 4; // y becomes 20
Think → Predict → Reveal

Evaluate without running code

Predict
int result = 20 - 6 / 2 * 3;

What is result?
↻
Answer
11. Division and multiplication have higher precedence than subtraction and are evaluated left-to-right: 6/2 = 3, 3*3 = 9, then 20-9 = 11.
↻
Named constants

If a value should not change, give that fact a name

Typed constant

const int MAX_ATTEMPTS = 3;

The compiler knows the type and prevents assignment to the constant.

Preprocessor definition

#define MAX_ATTEMPTS 3

This is text replacement handled before compilation.

Beginner best practice: prefer a typed const when you need a normal named constant in C++.
