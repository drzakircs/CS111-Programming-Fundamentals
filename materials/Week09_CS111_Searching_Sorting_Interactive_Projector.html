C++ function: binarySearch

28 / 63

Core implementation

01int binarySearch(const int a[], int n, int key) {
02 int low = 0, high = n - 1;
03 while (low <= high) {
04 int mid = low + (high - low) / 2;
05 if (a[mid] == key) return mid;
06 if (a[mid] < key) low = mid + 1;
07 else high = mid - 1;
08 }
09 return -1;
10}
Function assumes a is sorted in ascending order.

C++ code: bubbleSort

47 / 63

Standard nested-loop implementation

01void bubbleSort(int a[], int n) {
02 for (int pass = 0; pass < n - 1; pass++) {
03 for (int j = 0; j < n - 1 - pass; j++) {
04 if (a[j] > a[j + 1]) {
05 int temp = a[j];
06 a[j] = a[j + 1];
07 a[j + 1] = temp;
08 }
09 }
10 }
11}
After each full pass, one more largest value settles at the right.

Store key, shift larger values, insert key

01void insertionSort(int a[], int n) {
02 for (int i = 1; i < n; i++) {
03 int key = a[i];
04 int j = i - 1;
05 while (j >= 0 && a[j] > key) {
06 a[j + 1] = a[j];
07 j--;
08 }
09 a[j + 1] = key;
10 }
11}
