Session 04

Variables, Literals & Data Types

📦

Store

Variables give names to values in memory.

🏷️

Name

Identifiers must follow language rules.

🧬

Type

Data type controls meaning, size and operations.

Ask: “If a program receives a student age or a login attempt count, where does that value live while the program is running?”

Formal term: A variable is a named memory location used to store a value during program execution.

Three related ideas

Declaration, initialization and assignment

Declaration

int age;

Tell C++ to create a variable named age.

Initialization

int age = 18;

Create the variable and give its first value.

Assignment

age = 20;

Replace the current value with a new value.

Beginner rule: initialize variables before using them.

Literals

A literal is a fixed value written directly in code

10

Integer literal

3.14

Floating literal

'A'

Character literal

"Ali"

String literal

A literal has no variable name. It is directly placed in the program text.

Identifiers

Identifier: the programmer-chosen name

Valid identifier rules

  • Can contain letters, digits and underscore.
  • Cannot start with a digit.
  • Cannot be a C++ keyword.
  • No spaces or special symbols.
  • Case-sensitive: age and Age differ.

Professional naming

  • Use meaningful names.
  • failedAttempts is better than x.
  • Use consistent style.
  • Avoid confusing abbreviations.

Common beginner confusion

char, string and bool

char

Stores exactly one character.

char grade = 'A';

Use single quotes.

string

Stores a sequence of characters.

string user = "Ali";

Use double quotes.

bool

Stores logical truth.

bool locked = true;

Use true or false.

Size of a data type

sizeof helps us ask: how much memory?

Concept

Different data types may require different memory sizes.

sizeof returns the size in bytes for a type or variable.

C++ fragment

cout << sizeof(int); cout << sizeof(double); cout << sizeof(char);

Exact sizes can vary by system and compiler.

Scope

Scope controls where a variable can be used

Plain idea

A variable is not necessarily visible everywhere in a program.

Its scope is the region where the name is recognized.

int main() { int attempts = 0; // visible inside main cout << attempts; } // attempts is not visible here

For beginners: declare variables close to where they are needed and do not reuse confusing names.

Named constants

Some values should not change

Variable

int maxAttempts = 3; maxAttempts = 5; // allowed

Value can change during execution.

Named constant

const int MAX_ATTEMPTS = 3; // MAX_ATTEMPTS = 5; // error

Value is fixed after declaration.

Security example: Use a constant for a policy limit such as maximum login attempts.

Symbols that perform operations.

Predict the result

Predict

What value is stored in x?

Answer

Operator precedence

C++ does not simply evaluate left to right

Expression

int result = 2 + 3 * 4;

Multiplication has higher precedence than addition.

Evaluation

Step 13 * 4 = 12
→
Step 22 + 12 = 14

Use parentheses when the intended order must be absolutely clear.

Ask students

Final value?

Predict
int x = 5;
x = x + 2;
What is the final value of x?
↻
Answer
7
Read old value 5 → add 2 → store 7 back into x.
↻
Multiple and combined assignment

Shorter updates, same logic

Regular form

score = score + 10; attempts = attempts - 1;

Combined form

score += 10; attempts -= 1;

Combined assignment is compact, but beginners should still understand the full form first.

Increment and decrement

Increasing or decreasing by one

Increment

count++; // same idea as: count = count + 1;

Used for counters and repeated processing.

Decrement

attempts--; // same idea as: attempts = attempts - 1;

Used when remaining chances decrease.

Ask students

Remainder operator

Predict
What is the result of 17 % 5?
↻
Answer
2
Because 17 divided by 5 gives quotient 3 and remainder 2.
↻
Negative remainder caution

Be careful with negative values and %

Why it matters

For positive values, remainder feels intuitive.

With negative values, beginners can make wrong assumptions.

Practical rule

For first-semester work, avoid relying on negative remainders unless you deliberately tested and understood the rule.

int r = -7 % 3;

When validating logic, test boundary and unusual values, not only comfortable positive values.

C++ input/output

cout sends data out; cin brings data in

Output

cout << "Enter age: ";

Displays a message on the screen.

Input

int age; cin >> age;

Reads user input into the variable.

<< points toward output stream. >> points from input stream into a variable.

Cascading output

Multiple values can be sent to cout

string user = "Ali"; int score = 80; cout << "User: " << user << " Score: " << score;

Output idea

User: Ali Score: 80

Cascading means chaining multiple << insertions in one output statement.

Formatting output

Clear output is part of good programming style

Hard to read

cout << total;

The user sees only a number.

Better

cout << "Total marks = " << total;

The output explains itself.

Readable output helps both users and programmers during debugging.

Type conversion

Sometimes values move from one type to another

Implicit conversion

C++ converts automatically when needed.

double x = 5; // int to double

Explicit conversion

The programmer requests conversion.

int y = static_cast<int>(3.9);

Overflow and underflow

Data types have limits

Overflow

A value becomes too large for the chosen type.

Result can be incorrect or unexpected.

Underflow

A value becomes too small to represent accurately, especially for floating-point types.

Precision may be lost.

Cyber Security connection: Later, understanding numeric limits helps explain input validation and memory-safety issues.

Characters and strings

Text data must be represented carefully

Character

char option = 'Y';

Exactly one character. Use single quotes.

String object

string username = "student";

Sequence of characters. Use double quotes and include <string>.

Common program errors

Beginner errors have patterns

Syntax error

The code violates C++ grammar.

cout << "Hi"

Logic error

The program runs, but the result is wrong.

avg = total / 2; // should divide by 3

Type mistake

The chosen type gives an unexpected result.

int avg = 7 / 2;

Problem-solving case study

Mini case: compute a simple login risk score

Problem

A program stores failed login attempts and calculates a simple score.

  • Base score = 20
  • Each failed attempt adds 15
  • Display final score
int baseScore = 20; int failedAttempts = 3; int riskScore = baseScore + failedAttempts * 15; cout << "Risk score = " << riskScore;

This is not an actual security model. It is a beginner-friendly expression-tracing example.
